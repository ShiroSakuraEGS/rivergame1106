# 🌊《瓦磘溝探索之旅》消失的河川記憶
### The Waoyao River Adventure｜兒童互動式河川教育遊戲

> 專為國小三至六年級學童設計的在地河川沉浸式冒險遊戲。  
> 志同道河 River Adventure Project ｜ 瓦磘溝環境守護教育推廣

---

## 📖 故事世界觀與核心設定

在中和與永和之間，有一條承載著百年水路生活記憶的河川——**瓦磘溝**。  
它曾是居民運送貨物、農田引水灌溉的命脈，見證了雙和聚落的興起。然而隨著都市化發展，生活污水與廢棄物讓瓦磘溝面臨嚴重考驗。

在故事中，瓦磘溝的「記憶之流」逐漸混濁，記錄在河川中的歷史、生態與守護之道開始消失，由生活污染物凝聚的「醜泥怪」也因此不斷壯大。玩家將跟隨**小水滴**、**河爺爺**與**小白鷺**的腳步，找回三枚失落的河川記憶碎片：
1. **🪨 歷史之石**：重回昔日水路，找回瓦磘溝的地方生活記憶。
2. **🍃 生態之葉**：走進河岸綠意，認識小白鷺、翠鳥、夜鷺等動植物夥伴，清理外來垃圾。
3. **💧 守護之水**：揭露四大污染真相，在日常生活中做出正確守護抉擇。

> **核心精神**：真正讓河川恢復清澈的不是魔法，而是每個人在日常生活中的選擇與行動。醜泥怪並非天生惡魔，而是人類不當行為累積的縮影；當大家落實環保，醜泥怪也能轉身成為守護河川的巡邏提醒員！

## 🌟 遊戲章節與任務流程

- **序章：神祕的河川呼喚**（約 2 分鐘）
  - 遇見發光的小水滴，認識瓦磘溝位處新北市中和與永和的地理位置。
  - 醜泥怪初現，收下河爺爺的時光地圖展開冒險。
- **第一章：消失的時光之河**（約 4–5 分鐘）
  - 穿過時光之門，探索昔日運貨小木船、水圳農田、傳統聚落與防汛水道。
  - 通過時光記憶三道配對考驗，取得【歷史之石】，解鎖稱號「時光探索家」。
- **第二章：河川居民的求救信**（約 4–5 分鐘）
  - 生態大搜查：在河岸尋找小白鷺、夜鷺、翠鳥、紅尾伯勞、榕樹與腎蕨 6 位動植物鄰居。
  - 清理隨風飄散的塑膠袋、手搖杯、寶特瓶與油膩食物盒。
  - 取得【生態之葉】，解鎖稱號「生態觀察員」。
- **第三章：醜泥怪的秘密**（約 7–9 分鐘）
  - 揭開醜泥怪的垃圾倉庫：認識固體廢棄物、有機生活廢水、化學工業廢液與優養化四大污染源。
  - 四大日常污染危機行動決策（塑膠袋飛走、廢食用油回收、家庭洗劑、不明化學液體通報）。
  - 醜泥怪心聲釋放與角色轉變，取得【守護之水】，解鎖稱號「河川守護者」。
- **終章：河流重新說話了**（約 2–3 分鐘）
  - 三枚記憶碎片合一，河川重新恢復蔚藍光澤。
  - 醜泥怪脫去污泥，成為守護瓦磘溝的「河川提醒員」。
  - 簽署個人守護誓約卡，即時生成專屬《瓦磘溝小小守護者認證證書》（支援高畫質圖片下載與直接列印）。

## 🛠️ 技術特色

1. **GitHub Pages 零設定部署**：純前端靜態架構（HTML5、CSS3、Vanilla JavaScript），無須 Node.js、Python 或任何後端伺服器環境。
2. **Web Audio API 程式化合成音效**：內建水滴聲、潺潺流水環境音、答題音、和弦琶音與通關勝利號角，不需要從外部下載龐大音頻檔案，加載秒開、不受外部鏈結失效影響。
3. **結構化劇情資料檔**：所有對話、題目、角色名單均模組化抽離於 `js/storyData.js` 中，老師或推廣單位未來可隨時直接修改或擴充題目與生物項目。
4. **全響應式繪本風介面**：適配桌上型電腦、筆記型電腦、Chromebook、iPad 與手機觸控操作。
5. **正向鼓勵教育機制**：答錯不扣分、不挫敗，提供溫和的引導式提示協助再次思考。

## 🚀 如何發布至 GitHub Pages

1. **建立 GitHub 遠端倉庫**：
   在 GitHub 上點擊「New repository」，建立名為 `river-game` 或 `waoyao-adventure` 的公開倉庫（Public）。
2. **推送本機代碼**：
   ```bash
   git remote add origin https://github.com/<你的使用者名稱>/<你的倉庫名稱>.git
   git branch -M main
   git push -u origin main
   ```
3. **啟用 GitHub Pages**：
   - 進入 GitHub 倉庫頁面，點擊 **Settings**。
   - 在左側選單點擊 **Pages**。
   - 在 **Build and deployment** 下方的 **Source** 選擇 `Deploy from a branch`。
   - 在 **Branch** 選擇 `main`，資料夾選擇 `/ (root)`，點擊 **Save**。
4. **完成上線**：
   等待 1–2 分鐘後，即可透過專屬網址（例如：`https://<你的帳號>.github.io/<你的倉庫名稱>/`）直接在瀏覽器遊玩！
